# Автопилот OKX на сервере — круглые сутки, без Мака

Сейчас автопилот работает в окне на Маке. На сервере всё готово, но выключено. Включаете вы сами, один раз, за 10–15 минут.

Два автопилота на одном счёте не торгуют никогда: это проверяет «замок». Пока на Маке работает окно автопилота, установка на сервере откажется.

## Шаги

**1. IP сервера в ключе OKX.**
OKX → субаккаунт CRYPTO NOVA → API → ключ автопилота → «Изменить» → IP-адреса → добавить `91.99.193.20`.
- IP Мака (`188.4.179.38`) **не удалять**: по нему зеркало на Маке читает субаккаунт для карточки «Мой портфель».
- Право «Вывод» не включать.

**2. Файл ключей на сервере.** В Терминале на Маке:
```
ssh root@91.99.193.20
cp /opt/cnq/repo/deploy/okx/cnq-okx.env.example /etc/cnq-okx.env
chmod 600 /etc/cnq-okx.env
nano /etc/cnq-okx.env
```
- После `=` впишите 3 значения из `~/.cryptonova.env` на Маке: `OKX_API_KEY`, `OKX_API_SECRET`, `OKX_API_PASSPHRASE`.
- Слово `export` не писать. Остальные строки не трогать: токен GitHub установка возьмёт сама.
- Сохранить: Ctrl+O, Enter, Ctrl+X.

**3. Закройте окно автопилота на Маке.** В окне автопилота нажмите Ctrl+C. Окно зеркала не трогайте.

**4. Перенесите состояние автопилота на сервер.** В новом окне Терминала на Маке (Cmd+N):
```
scp ~/.cryptonova_okx_*.json ~/.cryptonova_public_real.json root@91.99.193.20:/root/
```
Если scp напишет, что файла `.cryptonova_public_real.json` нет, — не страшно, остальные файлы скопируются.

**5. Установка.** На сервере (окно с `ssh` из шага 2):
```
bash /opt/cnq/repo/scripts/okx_autopilot_server.sh install
```
- Скрипт проверит файл ключей и ключ с сервера (ордеров при проверке нет).
- Потом попросит написать **ДА**.
- Если он чего-то не принял, он напишет, что исправить.

**6. Проверка:**
```
bash /opt/cnq/repo/scripts/okx_autopilot_server.sh status
```
Должна быть строка «Замок автопилота: автопилот на сервере · сейчас торгует server».

## Дальше

- Мак можно выключать.
  - «Реальный счёт CRYPTO NOVA на OKX» (`web/public_real.json`) теперь обновляет сервер, раз в 15 минут. Мак сам перестаёт его писать.
  - Карточка «Мой портфель» обновляется, только пока на Маке работает зеркало.
- Двойной щелчок «CRYPTO NOVA» на Маке теперь открывает только окно зеркала.
- **Стоп:** «CRYPTO NOVA стоп» на Маке — останавливает и сервер. Или на сервере:
  ```
  bash /opt/cnq/repo/scripts/okx_autopilot_server.sh stop
  ```
  - Открытые фьючерсы остаются со своими стоп-лоссами на OKX.
  - Снять стоп с Мака: `cd ~/cryptonova-cockpit && bash scripts/okx_autopilot_mac.sh resume`.
  - Если останавливали командой `stop` на сервере, запустить снова: `bash /opt/cnq/repo/scripts/okx_autopilot_server.sh start`.
- **Вернуть на Мак.** На сервере:
  ```
  bash /opt/cnq/repo/scripts/okx_autopilot_server.sh uninstall
  ```
  Потом на Маке:
  ```
  scp 'root@91.99.193.20:/var/lib/cnq-okx/.cryptonova_*.json' ~/
  ```
  И двойной щелчок «CRYPTO NOVA», в окне автопилота написать ДА.

Ключи и содержимое `/etc/cnq-okx.env` никому не отправляйте, в том числе в чат.

## Мониторы «Иван тест» и «Мой портфель» на сервере (28.10)

Раньше их публиковало зеркало на Маке, поэтому с 22.10 карточки стоят. Теперь их можно запустить на сервере. Это только чтение: сервер ничего не покупает и не продаёт этими ключами. Файлы публикуются как раньше, зашифрованными (`web/ivan.enc.json`, `web/myspot.enc.json`), плюс `web/ivan_stats.json` — только статистика сделок Ивана, без баланса и позиций.

Публикует одна машина — та, на которой работает автопилот (замок). Если зеркало на Маке запустится снова, оно эти карточки публиковать не будет.

**1. Ключи только на чтение.**
- «Иван тест»: Bybit → аккаунт «Иван тест» → API → ключ с правом **Read-Only** (без Trade). Если ключ привязан к IP — добавьте `91.99.193.20`.
- «Мой портфель»: OKX → **личный** аккаунт (не субаккаунт CRYPTO NOVA) → API → ключ с правом **«Чтение»** (без «Торговля» и «Вывод»), IP `91.99.193.20`.

**2. Строки в файл ключей на сервере.**
```
ssh root@91.99.193.20
nano /etc/cnq-okx.env
```
Допишите в конец 7 строк (после `=` — значение, без слова `export`; значения есть в `~/.cryptonova.env` на Маке):
```
IVAN_BYBIT_KEY=
IVAN_BYBIT_SECRET=
IVAN_PASS=
MYSPOT_OKX_KEY=
MYSPOT_OKX_SECRET=
MYSPOT_OKX_PASSPHRASE=
MYSPOT_PASS=
```
`IVAN_PASS` и `MYSPOT_PASS` — те же фразы, что на Маке (панель открывает карточки ими). Сохранить: Ctrl+O, Enter, Ctrl+X.

**3. (Необязательно) история карточек с Мака.** В новом окне Терминала на Маке:
```
scp ~/.cryptonova_ivan.json ~/.cryptonova_myspot.json root@91.99.193.20:/root/
```
Без этого история начнётся заново (сделки Ивана за последние 60 дней подтянутся сами).

**4. Включить.** На сервере:
```
bash /opt/cnq/repo/scripts/okx_autopilot_server.sh monitors
```
- Скрипт проверит ключи с сервера. Ключ с правом торговли он не примет (строка «ОТКАЗ»).
- Потом включит таймер: каждые 15 минут.

**5. Проверка:**
```
bash /opt/cnq/repo/scripts/okx_autopilot_server.sh status
```
Внизу — таймер `cnq-okx-monitors.timer` и последние строки: «Иван тест: опубликовано…», «Мой портфель OKX: опубликовано…».

Выключить: `bash /opt/cnq/repo/scripts/okx_autopilot_server.sh monitors-stop`.
