# П. 198 — два кита держат одну монету: выходить по своему, по первому или по последнему выходу (18.11.2026)

**Вопрос.** 16–17.11 ZEC-лонг: мы копировали 金虎, второй кит той же стороны закрыл раньше, 金虎 — позже, и наш выход был на 2,2% лучше. Стоит ли правилом держать копию, пока её держит хоть один кит списка?

**Данные и метод (заранее, до результата).** Binance, ws_trips, 107 дней; решения = сделки трейдера по монете+стороне, слитые в 4 ч; планка живая (60 дн. до решения: ≥ 20 решений, win ≥ 70%, PF ≥ 2, плюс); вход +2 мин, выход +2 мин после кита, стоп −16% от нашего входа, издержки 0,11% + фандинг, 5-мин свечи. Книга как живая: одна копия на монету, ≤ 15 копий, дневной стоп 3%. Случай = наша копия кита A, пока другой кит B той же стороны пропущен как «монета занята». Три выхода нашей копии: по A (как сейчас), по первому из A/B, по последнему. Проход: n ≥ 20, сумма > 0, лучше в ≥ 55% различающихся случаев, сумма > 0 в обеих половинах. 2 альтернативы, основной пул — топ-10.

**Результат (Actions run 44257414102).**

| пул | случаев | по своему | по первому − по своему | по последнему − по своему |
|---|---|---|---|---|
| топ-10 | 24 | −31,6% (сумма), −1,32%/сл. | +11,1 (1-я половина −15,7, 2-я +26,7), лучше 59%, t 0,3 | −13,5 (1-я −19,0, 2-я +5,5), лучше 5 из 7, t −0,5 |
| все с планкой | 43 | −48,5%, −1,13%/сл. | +21,7 (−15,7 / +37,4), лучше 50%, t 0,5 | −16,7 (−19,0 / +2,4), лучше 65%, t −0,55 |

**Вывод.** Не прошло ни одно правило. «По последнему» чаще выигрывает понемногу, но один случай дал −26% (держали до стопа) — хвост съедает всё; «по первому» плюс только во 2-й половине. ZEC 16–17.11 — частный случай. Правило выхода не меняем; учёт таких пар вперёд уже идёт в п. 195.
