# Как подключить MetaTrader 5 к CRYPTO NOVA AI

Это займёт около 5 минут. Советник CryptoNovaBridge **только читает**. Он ничего не покупает, не продаёт и не меняет стопы.

Советник отправляет нам:
- ваши сделки (вход, выход, стоп, тейк);
- раз в 5 минут — открытые позиции и свечи.

Пароль от счёта **не нужен**, и мы его никогда не попросим. Номер счёта уходит только в зашифрованном виде.

## 1. Скопируйте файл

1. В MetaTrader 5 откройте меню **Файл → Открыть каталог данных**.
2. Перейдите в папку `MQL5\Experts`.
3. Положите туда файл `CryptoNovaBridge.mq5`.

## 2. Скомпилируйте советник

1. Нажмите **F4**, откроется MetaEditor.
2. Слева найдите `Experts → CryptoNovaBridge.mq5` и откройте его.
3. Нажмите **F7** («Компилировать»). Внизу должно быть «0 errors».
4. Закройте MetaEditor.

## 3. Разрешите связь с нашим сервером

1. В MetaTrader 5: **Сервис → Настройки → Советники**.
2. Поставьте галочку **«Разрешить WebRequest для следующих URL»**.
3. Добавьте строку `https://app.crypto-capital.app`.
4. Нажмите **OK**.

## 4. Запустите советник на одном графике

1. Откройте один график, например XAUUSD. Хватит одного графика: советник видит все сделки счёта.
2. В «Навигаторе» перетащите **CryptoNovaBridge** на этот график.
3. На вкладке «Общие» поставьте галочку **«Разрешить алгоритмическую торговлю»**. Советнику она нужна только для работы с интернетом, торговать он не будет.
4. На вкладке «Входные параметры» в поле **InpToken** вставьте токен, который вам передали. Больше ничего менять не нужно.
5. Нажмите **OK**. В правом верхнем углу графика появится значок советника.

## 5. Проверьте

Откройте вкладку **«Эксперты»** внизу терминала. Там должна появиться строка `CryptoNovaBridge: started`.

Если видите сообщение:
- **«add … in Tools → Options»** — повторите шаг 3;
- **«the token is not accepted»** — проверьте, что токен вставлен целиком.

## Важно

- Терминал должен быть включён, пока вы торгуете. Если компьютер выключен, сделки подождут в очереди и уйдут, когда терминал снова запустится.
- Токен личный: не публикуйте его и не пересылайте никому.
- Отключить советник можно в любой момент: правый клик по графику → «Советники» → «Удалить».
