# П. 123 — «повторяемость» кита Binance при отборе (10.11.2026, 03:30 Афин)

Вопрос: счёт OKX повторяет только решения в монетах, у которых есть своп USDT на OKX. Киты Binance торгуют и TradFi (акции/металлы), и монеты, которых на OKX нет (п. 113: у списка 53% таких решений за 04–08.11). Лучше ли судить такого кита только по решениям, которые мы можем повторить?

## Заранее записанный план (до результатов)
- Решения, отбор, копия и книга — как в п. 116 (bn_whale_fresh.py / cohort_sim): 60 дн. до решения, win ≥ 70%, PF ≥ 2, ≥ 20 решений, P&L > 0; топ-10 по 60-дн. P&L; вход и выход +2 мин, стоп −16%, издержки 0,11% + фандинг; дневной стоп 3%, до 15 копий, одна на монету. Копируются только повторяемые решения (текущий список свопов OKX).
- База = живое правило: отбор по всем решениям. Вариант (один порог): если ≥ 50% решений кита за 60 дн. не повторяемы — отбор и рейтинг только по повторяемым (всё так же ≥ 20).
- Проходит, только если парный дневной t ≥ 2,5 в обеих половинах, а худший день и просадка не хуже 1,25× базы. 1 вариант, 1 источник (у китов OKX/HL проблемы нет).
- Скрипт: scripts/research/bn_whale_norepeat.py, прогон research-bn-whales (mode norepeat) 42734484632.

- Доля непокрываемых решений на Binance по месяцам: июль 22%, авг 12%, сен 18%, окт 17%, ноя 13% (всего ≈ 16%). Тяжёлые случаи: два кита с 58% и 72% непокрываемых решений.

## Оговорки
- Только закрытые позиции (п. 104) — итог обоих вариантов завышен одинаково.
- Список свопов OKX текущий, не исторический (монеты, добавленные позже, считаются повторяемыми задним числом).
- Мало различающихся дней (13) — вывод «не лучше», а не «точно хуже».

## Вывод
Отбор только по повторяемой части не улучшает стол — ничего не меняем. Полезно видеть долю непокрываемых решений у каждого кита на пересмотре — записано как п. 124 (только измерение).
