# Малые неликвидные спокойные монеты с широким диапазоном (п. 59, 30.10.2026)

**Идея.** arXiv 2604.26747 (2026): LLM-агент перебрал 25 факторов; лучший — «малая капитализация + низкий оборот + низкая
волатильность + большой дневной диапазон». Вне выборки 2024–25 Sharpe 1.55 при 0.05% на сторону, но 0.46–0.57 (≈ 1.5%/год)
при 0.1–0.3%. Мы ждали, что издержки его убьют, и проверили честно на гораздо более широком наборе.

**Правило (задано до прогона, 1 вариант, без подбора).** Раз в 7 дней на дневном закрытии: все бессрочные USDT-M Binance с
21 днём без пропусков и средним оборотом за 20 дней ≥ $1 млн. Признаки за 20 дней: оборот (чем ниже, тем лучше),
волатильность дневных доходностей (ниже — лучше), средний диапазон (high − low)/close (выше — лучше). Сумма рангов →
лонг верхний квинтиль, шорт нижний, равные доли, 0.5× на сторону. Доходность = цена закрытие-к-закрытию + настоящий
фандинг; издержки 0.05% + 0.15% проскальзывания (неликвидные) на каждую единицу оборота. Снятая монета закрывается по
последнему закрытию. Скрипт: `scripts/p59_study.py` (research-voltbreak, mode f59).

**Данные.** data.binance.vision, 1d + fundingRate, 2020-01 → 2026-09: 895 символов, 820 пригодны, 29 сняты с торгов.
Медиана вселенной 184 монеты в неделю (20…596). Плацебо: та же вселенная, случайные квинтили, 20 прогонов.
Поправка на удачу: N = 526 → порог Sharpe 1.38.

**Результат — не прошло.**

| --- | --- |
| Sharpe счёта | 0.32 (половины 0.51 / 0.03) против порога 1.38 |
| Доходность / просадка | +4.4% в год / −28.0% |
| Недели | 348, средняя +0.23%, t 1.57 (нужно ≥ 2) |
| Плацебо | Sharpe средний −0.97, p95 −0.39 (фактор выше плацебо) |
| 2024+ (окно статьи) | Sharpe 0.20 |
| По годам | 2020 −16.4%, 2021 +42.2%, 2022 +21.3%, 2023 −12.5%, 2024 +6.4%, 2025 +1.9%, 2026 −2.8% |
| Части в год | цена +19.0%, фандинг −6.7%, издержки −6.0% |
| Ноги отдельно | лонг Sharpe 0.56 (+16.0%/год); шорт Sharpe −0.38 (−22.5%/год) |
| При издержках статьи (0.07%) | Sharpe 0.52 (половины 0.68 / 0.28), +8.6%/год, просадка −27.5% |
| BTC для сравнения | Sharpe 0.91, +43.8%/год, просадка −76.7% |

**Вывод.** Фактор существует (лучше случайного выбора), но слабый и угасает: почти весь плюс — 2021–2022, после 2023 около
нуля. Цену съедают фандинг и издержки, шорт-нога убыточна (как во всех наших шорт-проверках, п. 50). Совпадает с самой
статьёй при реальных издержках (Sharpe ≈ 0.5). Стол не создаётся, семья закрыта. Лонг-нога одна (Sharpe 0.56) хуже
простого держания BTC — отдельно не проверяем, чтобы не подбирать по уже увиденному.

Статистика прошлого, не обещание и не финансовый совет.
