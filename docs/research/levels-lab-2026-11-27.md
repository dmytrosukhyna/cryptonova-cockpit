## 4. Сетка стопов, выходов и входов на 7 наборах монет
- Наборы монет: только BTC, только ETH, только SOL, BTC+ETH+SOL, топ-5, топ-10, все 30.
- Входы (6 видов):
  - как у стола (закрытие часа);
  - сразу при касании;
  - подтверждение на 15m;
  - лимит за уровнем на 0,25 ATR (ловит вынос);
  - ордерблок с зоной по телу свечи;
  - ордерблок с зоной по тени.
- Стопы (8): 0,5 / 1 / 1,5 / 2 / 3 ATR(1ч), ATR(4ч), за свингом, за выносом.
- Цели (4): 1,5R / 2R / 3R / уровень.
- Ведение (7): без, безубыток на 1R, трейл, половина на 1R + остаток, выход через 12 / 24 / 48 ч.
- К этому — 120 вариантов семейств v2 в каждом наборе.

**Всего 19 656 проверок, порог t ≥ 4,75.** Правила записаны до прогона: коммит ad645d09, run 45956460807.

- Ордерблоки на одиночных монетах держатся около нуля или слегка в плюсе, но это сотые-десятые доли процента при t ≤ 1,2.
