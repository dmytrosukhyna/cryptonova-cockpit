## Как считали
- **Источник.** Сообщения владельца в рабочей сессии с 10.11. Взяты только написанные им самим, без сводок агентов и системных сообщений. Высказывания 04–10.11 известны только по сводке сессии, без точного времени. Для них время приблизительное, и это помечено.
- **Цены.** Часовые свечи OKX, спот (QNT — своп), с 03.11 по 19.11 22:00 UTC. Скачаны прогоном `research-owner-calls` (скрипт `scripts/research/owner_calls_prices.py`).
  - PEPE есть только до 18.11 16:00 UTC: обрезаны данные прогона.
  - XTEN ещё не торгуется ни на OKX, ни на Bybit, ни на Binance.
- **Цена в момент высказывания** — закрытие последней полной часовой свечи до него. Время — UTC.
- **Горизонт** указан у каждого пункта: 1 день, 7 дней или «до сейчас» (19.11 22:00 UTC).
- **Вердикт:**
  - прав / не прав;
  - частично (в итог идёт как ½);
  - рано судить (в итог не идёт).
- **Сравнение монет.** Монету сравниваем с BTC за тот же отрезок. Весь период рынок падал: BTC −16% с 11.11, −23% с 05.11. Поэтому «прав» по монете чаще значит «упала меньше рынка», а не «заработала».

## Оговорки
- **Выборка мала.** 14 засчитанных высказываний, все за две недели падающего рынка. По такой выборке нельзя сказать, хорош ли прогноз вообще. Можно сказать только, как он сработал в этом спаде. Одна монета (VVV) решает почти весь «плюс» по монетам.

- **Сравнение с BTC в падающем рынке мягкое.** «Прав» по GRASS — это меньший убыток, а не прибыль.
- **Пункты 1–3** известны только по сводке сессии, время приблизительное. Вердикт по № 1 не зависит от точного дня: с 04.11 по 07.11 BTC был $77–81 тыс., сейчас $62 тыс.
