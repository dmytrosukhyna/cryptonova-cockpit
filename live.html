Сигналы

Исполнение через API

Кнопка «Исполнить» отправляет сигнал на ваш сервер (`POST /execute`, модуль cnq/execution/bingx_trade.py), который ставит лимитный вход, стоп и 3 цели на BingX. По умолчанию — демо-счёт VST; реальный счёт включается отдельным ключом на сервере. Из этой страницы секреты биржи не используются.

Стакан (Binance Futures, live)

Полоса — объём на уровне относительно максимального в окне. Жирным — заявки ≥ 5× среднего (крупные). Дисбаланс считается в ±1% от цены: + значит больше покупателей в стакане. Стакан — это лимитные заявки, их могут снять; это фильтр, не сигнал.
