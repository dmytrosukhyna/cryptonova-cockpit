# Шорт листингов на MEXC и Hyperliquid — проверка 19.10.2026

Вопрос: если то же правило работает на большем числе бирж, сделок будет больше.

Правило то же, что на живом счёте:
- шорт через 4 часа после первой свечи;
- стоп +30%, исполнение на 1% хуже стопа;
- выход через 14 дней;
- пропускаем монеты, выросшие на 10% и больше за первые 4 часа;
- издержки 0.14% на сделку.

Скрипт `scripts/listings_more_study.py`.

## MEXC: 334 листинга с 2024 года, около 10 в месяц

**Результат:** в среднем **−2.1%** на сделку, в плюсе 45% сделок, 29% закрылись по стопу.

| | Значение |
| --- | --- |
| Без пампов (296 сделок) | −1.2% на сделку |
| Оборот за первые 4 часа: малый / средний / большой | +3.3% / −1.9% / −5.1% |
| Счёт, 5% на листинг | ×0.76, просадка −38% |
| Счёт, 20% на листинг | ×0.27, просадка −87% |

По кварталам в основном минус. Последние два квартала в плюсе: 2026Q3 +3.0%, 2026Q4 +7.0%. Но это короткий кусок, а не
устойчивый результат.

**Почему так, гипотеза:** MEXC выставляет монеты раньше и мельче. Потом многие из них растут на листинге у крупных бирж.

Фандинг в этой проверке почти не учтён: API отдал только последние записи. Поэтому результат может быть немного другим, но
знак минуса это вряд ли меняет.

## Hyperliquid

У Hyperliquid в открытом доступе только последние 5 000 часовых свечей. За это окно нашёлся всего один листинг, поэтому
проверить нельзя.
