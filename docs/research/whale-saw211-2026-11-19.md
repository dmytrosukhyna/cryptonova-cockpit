# П. 211 — пауза по «пиле» (19.11.2026, глубокое исследование 09:00)

**Вопрос.** После 2 минусовых сделок одного кита в одной монете за 24 ч — не копировать эту пару 24 ч (повод: 18–19.11 leaf-ye ETH, 5 минусов подряд, стол −$97.29).

**Порог (заранее, из backlog):** сумма лучше, потеря прибыли плюсовых ≤ 20%, n серий ≥ 15; иначе — запись вперёд.

## Данные
- data/whale_trades/*.jsonl (04.11–19.11): 27 010 закрытых сделок 240 трейдеров (bn 3 988, okx 22 078, прочие 944).
- Доход копии = сторона × (выход/вход − 1) − 0,10% издержек, обрезка снизу −16% (наш защитный стоп, только по цене закрытия). Задержка +2 мин не моделируется (внутридневных цен в этом файле нет) — оговорка.
- Сигнал строится только из уже закрытых сделок кита (без заглядывания вперёд): пауза начинается с закрытия 2-го минуса, если оба минуса закрыты в пределах 24 ч.
- Отдельно — журнал стола «Киты» (web/whales_live.json desk.closed, 160 копий с 19.10).
