# Golden Donut: connecting your MT5 account (read-only)

We only **watch** the account: trades, open positions, balance changes in %. Nothing can be traded, changed or withdrawn with what you send us. A demo account is fine.

## What we need

1. **Login**: your MT5 account number (digits only).
2. **Server**: the exact server name, for example `Broker-MT5 Live` or `Broker-Demo`. Copy it exactly, letter for letter.
3. **Investor password**: the read-only password of the account.

**Never send the master (trading) password.** We do not need it, and our server rejects it.

## Where to find the login and server

- **MT5 on the phone:** Settings → tap your account at the top. The number is the login; the line under the broker name is the server.
- **MT5 on desktop:** File → Login to Trade Account. The window shows the login and the server.

## How to get the investor password

Use any one of these:

- **Email from the broker.** When the account was opened, the broker sent the login, the master password and the investor password (sometimes called "read-only password").
- **MT5 desktop (Windows or Mac):** Tools → Options → Server → Change → enter the current master password → choose **"Change investor (read only) password"** → type a new one → OK.
- **MT5 on iPhone:** Settings → your account → the "…" menu → Change Password → **Investor password**.
- **MT5 on Android:** Manage Accounts → the "⋮" menu on the account → Change Password → **Change investor password**.
- **Broker's client cabinet:** open the account → Change password → investor / read-only password.

If you are not sure which password you have: with the investor password you can log in and see everything, but the Buy/Sell buttons do not work.

## How to send it

- Login and server: any way you like.
- Investor password: **only privately** to the owner (a direct message), or type it yourself into the secure form he shows you. **Never post it in a group chat.**

You can change the investor password at any time; that switches our access off immediately.

## Памятка владельцу (по-русски)

Мост к счёту — сервис MetaApi. Аккаунт в нём нужно создать самому: мы не можем регистрировать аккаунты за вас.

1. Зарегистрируйтесь на `app.metaapi.cloud`: email и пароль.
2. Откройте раздел **API access** и скопируйте токен.
3. На cryptonova.vip откройте вкладку **Golden Donut** → «Подключение».
4. Введите логин, сервер и пароль инвестора от трейдера. Токен MetaApi вставьте в четвёртое поле: он нужен один раз.
5. Нажмите **«Подключить»**. Через 1–3 минуты нажмите «Проверить подключение».

Что важно знать:
- Токен и пароль не пишите в чат. Они вводятся только в эту форму и обратно нигде не показываются.
- Пароль инвестора мы у себя не храним: после подключения он остаётся только в MetaApi.
- Кнопка «Отключить» удаляет счёт из MetaApi и токен с нашего сервера.
- Стоимость MetaApi: тариф Regular — $30 в месяц без НДС, один счёт MT включён, есть 7 дней пробного периода и $5 бонуса при регистрации. Так указано на сайте metaapi.cloud; перед оплатой проверьте цену в кабинете.
