# Поправки к демо-результатам

Только дописываем, прошлые записи не правим. Сами сделки не переписываются: поправка — отдельная строка в базе счёта, она входит в итог и видна в отчёте счёта (`adjustments` в web/paper.json).

## 22.10.2026 — fix-2026-10-22 (аудит 20.10, раздел 03 §4)

**Что было не так**
- **Проскальзывание у шортов.** Шорт по рынку открывался по цене на 0,02% *выше* сигнала, то есть в свою пользу. Теперь на 0,02% ниже, против сделки.
- **Фандинг не учитывался.** Удержание длится от суток до 2 недель. Теперь каждые 8 ч (00, 08, 16 UTC) лонг платит ставку × объём позиции, шорт её получает.
  - Источник ставки — история биржи в базе движка.
  - Пока расчёту меньше 2 ч, можно взять текущую ставку.
  - Если данных нет, расчёт записывается как «нет данных» и стоит 0 $, ставка не выдумывается.
- **Устаревшая цена входа.** B, E, G и X входили по открытию свечи, которая могла быть открыта 15+ минут назад. Теперь вход по самой свежей цене. Если свечи в базе старше 30 мин, вход по рынку не делается.
- **Свеча входа не проверялась на стоп.** Теперь, пока она последняя, стоп проверяется по живой цене каждую минуту.

**Как учтено прошлое**
- Один раз на каждый счёт добавлена строка `fix-2026-10-22` (таблицы `paper_adjustments` и `own_adjustments`). В неё входят:
  - точная разница по проскальзыванию у шортов, открытых по рынку до исправления;
  - фандинг закрытых сделок по истории биржи. Каждый расчёт записан в `funding_ledger` и больше не начисляется.
- Цену входа задним числом не пересчитать: в базе только 15-минутные свечи. Эта часть влияет только на будущие сделки.

**Оценка влияния по открытым данным на 21.10 22:09 UTC.** Точную сумму посчитает сервер при первом запуске, она появится в отчёте счёта.
