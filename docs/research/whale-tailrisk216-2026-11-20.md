# П. 216 — половинный риск пары кит+монета на 72 ч после «хвостовой» копии ≤ −8% (20.11.2026, глубокое исследование 03:00 Афин)

**Вопрос.** После того как копия пары «кит + монета» закрылась с ходом цены ≤ −8% против нас (хвост, как ARB −$128 на столе), копировать эту пару 72 ч с риском 1,5% вместо 3%.

**Порог (заранее, из backlog):** просадка лучше в обеих половинах, доход хуже не больше чем на 10%; только демо.

## Данные и метод
- data/whale_trades/*.jsonl 04–20.11: 27 270 закрытых сделок 252 трейдеров (bn 4 074, okx 22 222), дубли по (трейдер, id, монета) убраны.
- Доход копии = сторона × (выход/вход − 1), снизу −16% (защитный стоп), минус 0,10% издержек. Задержка +2 мин не моделируется (нет внутридневных цен) — оговорка, как в п. 211/213.
- Пометка без заглядывания вперёд: сделка пары открыта в течение 72 ч после закрытия её копии с ходом ≤ −8%.
- Равный вес по дням, половины — по медианной дате закрытия (как в п. 213).
- Вариантов: основное правило (−8%, 72 ч) + 4 проверки чувствительности (−5%/72 ч, −12%/72 ч, −8%/24 ч, −8%/168 ч) × 3 выборки = 15 сравнений; решение только по основному правилу.

## Результат (основное правило −8%, 72 ч)
| выборка | помечено | средняя помеченных / всех | доход: 3% → половинный | макс. просадка |
|---|---|---|---|---|
| все, весь период | 1 687 | **+2,37% / +1,36%** | +169,4 → +160,3 (−5,4%) | −2,88 → −2,83 |
| все, 1-я половина | | | +74,5 → +71,5 (−4,0%) | −1,00 → **−1,06 (хуже)** |
| все, 2-я половина | | | +86,5 → +81,7 (−5,5%) | −1,61 → −1,59 |
| Binance | 57 | +1,99% / +1,44% | −1,0% | без изменения |
| OKX | 1 622 | +2,38% / +1,36% | −6,4% | −4,44 → −4,39 |

Чувствительность: −5%/72 ч — доход −8,6%, просадка хуже везде; −8%/168 ч — доход −8,6%, просадка почти та же; −8%/24 ч — доход −1,6%, просадка −2,88 → −2,56 (1-я половина без изменения); −12%/72 ч — доход −0,6%, просадка −2,88 → −2,43, но в 1-й половине хуже (−1,00 → −1,05), помечено всего 463 сделки, средняя помеченных +0,93% против +1,36%. Ни один вариант не проходит «обе половины», а после 15 сравнений слабые улучшения не значимы.

Журнал стола «Киты»: в опубликованном срезе 20 последних закрытых копий — ни одной пометки; ARB −$128 был раньше среза (в п. 213 он дал почти всю «экономию»).

## Вывод
**Не прошло.** Сделки пары после хвостового убытка у этих трейдеров в среднем *лучше* обычных (+2,4% против +1,4%: трейдер часто перезаходит в ту же монету по лучшей цене), поэтому урезать их размер теряет доход, а просадку почти не меняет и в 1-й половине ухудшает. Правило не вводим ни в демо, ни в реальный счёт. Хвостовой риск закрыт стопом −16% и правилом «5 копий подряд в минусе → в B».

Побочная мысль (не правило, только запись вперёд): п. 218 — помечать перезаходы пары после хвоста и смотреть их итог на живом столе; если подтвердится +1 п. п. на 30 случаях — это аргумент *не* выходить из пары после хвоста.

## Скрипт
```python
import json,glob,collections,datetime as dt,statistics as st,sys
T=[];seen=set()
for f in sorted(glob.glob('data/whale_trades/*.jsonl')):
  for l in open(f):
    try:r=json.loads(l)
    except: continue
    if r.get('kind')!='closed' or not r.get('entry') or not r.get('exit'): continue
    k=(r['trader'],r['id'],r['coin'])
    if k in seen: continue
    seen.add(k)
    s=1 if r['side']=='LONG' else -1
    raw=s*(r['exit']/r['entry']-1)
    ret=max(raw,-0.16)-0.001
    T.append(dict(tr=r['trader'],src=r['src'],c=r['coin'],o=r['open_t'],cl=r['close_t'],ret=ret))
T.sort(key=lambda x:x['o'])
by=collections.defaultdict(list)
for t in T: by[(t['tr'],t['c'])].append(t)
def flag(thr,hours):
  H=hours*3600e3
  for k,ts in by.items():
    starts=[t['cl'] for t in ts if t['ret']<=thr]
    for t in ts: t['flag']=any(s<=t['o']<s+H for s in starts)
def run(sub):
  days=sorted(set(dt.datetime.utcfromtimestamp(t['cl']/1000).date() for t in sub)); mid=days[len(days)//2]
  out=[]
  for half,cond in (('всё',lambda d:True),('1-я',lambda d:d<mid),('2-я',lambda d:d>=mid)):
    res={}
    for wname,wf in (('base',1.0),('half',0.5)):
      daily=collections.defaultdict(float);n=collections.defaultdict(int)
      for t in sub:
        d=dt.datetime.utcfromtimestamp(t['cl']/1000).date()
        if not cond(d): continue
        daily[d]+=(wf if t['flag'] else 1.0)*t['ret'];n[d]+=1
      dd=sorted(daily); avgn=st.mean(n[d] for d in dd)
      eq=pk=mdd=worst=0
      for d in dd:
        r=daily[d]/avgn; eq+=r; pk=max(pk,eq); mdd=min(mdd,eq-pk); worst=min(worst,r)
      res[wname]=(eq*100,mdd*100,worst*100)
    a,b=res['base'],res['half']; out.append((half,a,b,(a[0]-b[0])/abs(a[0])*100))
  return out
print('trades',len(T),'traders',len(set(t['tr'] for t in T)),'days',min(t['cl'] for t in T),max(t['cl'] for t in T))
for thr,h in ((-0.08,72),(-0.05,72),(-0.12,72),(-0.08,24),(-0.08,168)):
  flag(thr,h)
  for name,sub in (('все',T),('bn',[t for t in T if t['src']=='bn']),('okx',[t for t in T if t['src']=='okx'])):
    nf=[t['ret'] for t in sub if t['flag']]
    o=run(sub)
    print(f"thr {thr} {h}h {name}: n {len(sub)} flagged {len(nf)} mean_f {100*st.mean(nf or [0]):+.2f}% all {100*st.mean(t['ret'] for t in sub):+.2f}%")
    for half,a,b,loss in o: print(f"   {half}: доход {a[0]:+.1f}→{b[0]:+.1f} (−{loss:.1f}%) mdd {a[1]:.2f}→{b[1]:.2f} worst {a[2]:.2f}→{b[2]:.2f}")
```
