# П. 279 · «Навык, а не удача»: фильтр случайности и концентрации поверх живой планки (27.11.2026)

**Вопрос.** Статья «Beyond Profit Rankings» (arXiv 2610.34754, 2026) советует выбирать smart money не по прибыли, а по признакам навыка: устойчивость по окнам, малая доля прибыли от немногих сделок, проверка на случайность. Устойчивость уже проверена в п. 283 (не прошла). Здесь — две остальные, как одно правило.

**Метод (записан до результата, один вариант).** Скрипт `scripts/research/bn_whale_skill279.py`, прогон research-bn-whales `skill279` (run 46005239182, ветка research/20261127-1515-skill279).
- Книга T и фильтры как в п. 282/283: копия +2 мин, выход +2 мин после трейдера, стоп −16%, издержки 0.20% за круг.
- PIT — живая планка на момент входа (60 дн. до входа: ≥ 20 решений, ≥ 70% в плюсе, PF ≥ 2, сумма > 0).
- SKILL — PIT и оба условия на тех же прошлых решениях (после издержек): (а) t средней сделки ≥ 2; (б) 3 лучших решения дают ≤ 50% валовой прибыли.
- DROP — PIT, но не SKILL. Ворота те же, что в п. 283: SKILL лучше PIT в обеих половинах; t по дням разницы SKILL − DROP ≥ 2; t по дням SKILL ≥ 2; потеря копий ≤ 40%.

**Что дальше.** Живая планка не меняется. Все три признака статьи («устойчивость», «случайность», «концентрация») проверены — ни один не добавляет к планке 70% / PF 2 / 20 решений. Новый пункт 290 — устойчивость t по дням к отдельным дням.
