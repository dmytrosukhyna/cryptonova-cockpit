# Шорты — можно ли зарабатывать на падении? Проверка 16.10.2026

Автопилот торгует только лонги (откупы перегибов). Проверены 7 идей для шортов на 18 монетах, реальные данные 2023–2026 (`scripts/shorts_test.py`), выход через 4/8/24 ч, издержки включены.

| Идея | лучший вариант | по годам |
|---|---|---|
| Медвежий рынок, рост +5% за 4 ч → шорт | −0.50% на сделку | все годы в минусе |
| Медвежий рынок, рост +8% за 4 ч → шорт | −1.1% | все в минусе |
| Медвежий, рост + открытый интерес +10% | −0.69% | 3 из 4 в минусе |
| Фандинг ≥ 0.03% и рост +10% за сутки → шорт | +0.30% (8 ч) | 2023 ≈ 0 — слабо |
| Рост +20% за сутки → шорт | −0.24% | 2023–2024 в минусе |
| Рост +20% за сутки → лонг (импульс) | −0.11% | 2025–2026 в минусе |
| Медвежий, откуп после падения → шорт | −0.05% | |

**Вывод.** На этих монетах шортить отскоки и перегревы не выгодно — крипта за эти годы росла, и ралли чаще продолжаются, чем ломаются. Единственный кандидат (шорт перегрева при высоком фандинге) слишком слабый. Автопилот остаётся только в лонгах; на медвежьем рынке защита — не шорты, а меньший размер и пауза (режим риска).

в п. 36: откат P зарабатывает только в дни массовых распродаж). С прошлыми проверками (16.10, раунд 11 19.10, п. 33) это пятая
подряд отрицательная проверка шортов по направлению. **Для реального счёта шорт-правила не предлагаем.**

Что дальше (в очередь): (1) «вывернутое» D — лонг после объёмного пробоя минимума вне «роста» (откуп капитуляции), с плацебо и

фандинг, раз в неделю) — шорт как ногу пары, а не как ставку на падение; (3) ОИ-версия F на посуточных файлах 2022–2026.
