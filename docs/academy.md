# Обучение CRYPTO NOVA (academy.json)

Курс для приложения: 5 уровней, 38 уроков — «Знакомство с CRYPTO NOVA» (гид со стрелками по экранам),
«С нуля», «Инвестор», «Трейдер», «Профи». Файл: `web/academy.json`, на сайте — `https://cryptonova.vip/academy.json`.

Схема урока: `id`, `title`, `minutes`, `goal`, `cards[]` (title, text ≤ 300, example ≤ 220, `art` — ключ иллюстрации,
необязательно `chart` line/bars/split; в уровне L0 ещё `screen` и `callouts` — стрелки на экран приложения),
`remember[]`, `quiz[]` (3 вопроса, `answer` — индекс верного варианта, `why`).

Правила текста: очень простым языком, пример из жизни в каждом уроке, цифры цифрами, без обещаний дохода,
реальные деньги — только с 18 лет. Курс написали 5 авторов по одному правилу и проверил отдельный редактор
(факты, арифметика, ответы тестов). Цифры «копилки» — проверка на реальных ценах BTC с комиссией 0.1%,
на 19.10.2026. Не финансовый совет.
