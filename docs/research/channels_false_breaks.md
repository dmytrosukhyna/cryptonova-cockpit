# Коридоры и ложные пробои — проверка 16.10.2026

Скрипт `scripts/channel_test.py`: 18 монет, 4-часовые свечи, 2020-09 → 2026-09, издержки 0.14% за сделку, стоп срабатывает первым внутри свечи. Результат в R (1R = риск сделки).

| Гипотеза | сделок | средний R | винрейт | по годам |
|---|---|---|---|---|
| Случайный вход (база), стоп/цель 1.5 ATR | 3 582 | −0.06 | 49% | все годы в минусе |
| Отскок от границы коридора (60 свечей) по тренду, цель — середина | 4 743 | **−0.11** | 40% | 5 из 6 лет в минусе |
| То же, цель — противоположная граница | 4 743 | −0.14 | 27% | |
| Коридор 120 свечей, цель — середина | 3 451 | −0.06 | 34% | |
| Коридор без фильтра тренда | 8 062 | −0.14 | 38% | |
| Ложный пробой 20-свечного экстремума, вход на возврате, цель 2R | 8 753 | −0.06 | 36% | |
| Ложный пробой 50 свечей, только лонги | 2 146 | −0.01 | 39% | 2024 и 2026 в минусе |
| Ложный пробой, цель 1R | 8 753 | −0.06 | 50% | |

**Вывод.** Обе классические идеи на этих монетах не лучше случайного входа (−0.06R — это почти ровно издержки), а отскок от коридора даже хуже. Коридор на графике остаётся подсказкой для глаз, в автопилот не идёт. Деньги на истории дают только откупы перегибов: каскад ликвидаций, паника, сброс открытого интереса (docs/research/oi_flush.md).

Следующие гипотезы: стенка в стакане у сильного уровня (сервер начинает копить снимки стакана), выходные и азиатская сессия отдельно, фандинг-экстремумы вместе со сбросом ОИ.
